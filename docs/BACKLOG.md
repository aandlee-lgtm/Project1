# PhotoSelect feature backlog

Feedback from testing is recorded here as product features. Nothing in this list is built,
versioned or released until the owner's message includes **build_new**; then the open items are
implemented, tested and shipped together as one new version.

| 22 | 2026-10-10 | **Fix: stars are not added automatically after an ordinary import.** The owner reports that in 1.7.0 they still import, then run Library → Plug-in Extras → Apply PhotoSelect Selections before the stars appear. Cause found in the plug-in: the capture-date lookup that finds imported photos (used for any import except Open in Lightroom Import + Add) calls Lightroom's catalog search inside plain Lua `pcall`. Planned: (1) use `LrTasks.pcall` for the search; (2) a fallback search by file name when the date search finds nothing; (3) the plug-in records its last error and how many photos each search found in plugin-status.txt, and PhotoSelect's Lightroom window shows it, so a failure is visible instead of silent; (4) the simulated catalog pauses like Lightroom does, so this class of bug fails the tests; (5) plug-in version 1.8.0, with PhotoSelect asking to reinstall it once. | Done in 1.8.0 |
